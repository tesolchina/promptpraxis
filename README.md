# Prompt & Praxis — companion code

Code, briefs, and tips for the artefacts featured in [*Prompt & Praxis*](https://procomm.ieee.org/ai-resources/prompt-and-praxis/) —
*Experiments in AI and professional communication*, a working series for IEEE ProComm written by
Simon Wang (Hong Kong Baptist University).

Each folder is one blog entry's artefact: the working code, the plain-language brief that produced it,
and the tips learned building it. Everything here was built with agentic AI from plain-language
instructions — no hand-written code.

| Folder | Entry | Artefact |
|---|---|---|
| [`plain2playable/`](plain2playable/) | Entry 1 — *From plain texts to playable* | Interactive listening lesson (HTML/CSS/JS + narrated audio) |

## The series' premise

AI is a **reasoning engine**, not an information engine: its output quality is bounded by the quality
of what you feed it. Fed permissioned source material and a precise plain-language specification, an
agentic AI returns working software — making teachers and other knowledge workers who don't program
able to build artefacts that, a year ago, required a development team.

These repositories exist so you can **remix**: take the brief, swap in your own source material, and
build your own version.
