# plain2playable — "From plain texts to playable"

Companion code for **Entry 1** of [*Prompt & Praxis*](https://procomm.ieee.org/ai-resources/prompt-and-praxis/) (IEEE ProComm): a listening lesson on engineering communication, built by a language teacher with no programming — from a plain-language brief to an agentic AI.

## What's here

| Folder/file | What it is |
|---|---|
| `listeningdemo/` | The complete artefact — the interactive listening lesson embedded in the blog entry (HTML/CSS/JS + narrated audio). Open `listeningdemo/index.html` in a browser. |
| `brief.md` | The actual plain-language specification sent to the agent (lightly edited for clarity). |
| `tips.md` | Practical tips on interacting with an agent to build something like this — what worked, what failed, how to sequence a brief. |

## The pipeline in one line

> plain-language brief + permissioned source material → agentic AI (plan → write code → run → read errors → fix) → playable artefact
