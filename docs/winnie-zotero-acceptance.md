## 2. Safe Import Instructions (Preserving Existing Library)

To prevent cluttering or duplicating your existing personal research library:

1. Open **Zotero Standalone** on your machine.
2. In the left collections pane, create a temporary collection named `__Test_PromptPraxis_Bib` and another named `__Test_PromptPraxis_RIS`.
3. **Test formats separately:**
   - Import `found.bib` into `__Test_PromptPraxis_Bib`.
   - In a separate action, import `found.ris` into `__Test_PromptPraxis_RIS`.
   - *Why separate?* Importing both files into the same collection will result in 10 records (each paper duplicated), making it difficult to verify whether 5 records were imported accurately.
4. When prompted by Zotero:
   - Select: **"Place items into a new collection"**.
   - Check: **"Copy files to the Zotero storage folder"** (if applicable).

## 3. Metadata Verification Checklist

For each imported file (`.bib` and `.ris`), inspect the 5 records in Zotero's right-hand details pane against `found.csv`:

- [ ] **Record Count:** Exactly 5 items appear in the collection.
- [ ] **Item Type:** Formatted as *Journal Article* or *Book Section* (not *Webpage*).
- [ ] **Titles:** Cleanly formatted without stray double braces (`{{...}}`) or broken characters.
- [ ] **Authors:** Surnames and first names placed in the proper fields (e.g. `Yan` in Last Name, `Da` in First Name; not reversed).
- [ ] **Publication Year:** Correct year (e.g. 2024, 2025).
- [ ] **DOI Field:** Clickable DOI link present (e.g. `10.1057/s41599-024-03543-y`).
- [ ] **Special Characters:** Check for clean handling of special characters (e.g. `&`, `%`, hyphens, quotation marks).
- [ ] **Missing Fields:** Confirm that records with missing authors or abstracts in OpenAlex (e.g. the Brill book chapter) remain cleanly empty rather than displaying errors or `undefined`.
